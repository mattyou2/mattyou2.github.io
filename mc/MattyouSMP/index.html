Powering the Server with ecosy

ecosy is a custom-coded Minecraft Skript economy system developed by us and shared publicly with the Minecraft community. It provides a lightweight, robust, and highly customizable economy framework.

# Ecosy Custom Economy Trigger
options:
    prefix: "&8[&aEcosy&8]"

command /balance [<player>]:
    aliases: bal, money
    trigger:
        set {_p} to player
        if arg-1 is set:
            set {_p} to arg-1
        send "{@prefix} &7%{_p}%'s Balance: &a$%{ecosy::bal::%{_p}'s uuid}%" to player
