Hoe Lumen werkt

Lumen draait volledig op eigen logica — er zit geen enkel AI-taalmodel onder de motorkap, ook niet van Anthropic/Claude. Alles wat je ziet komt rechtstreeks uit gratis, publieke bronnen:

  • 🧮 Rekenmachine — sommen (ook procenten, wortels, machten) worden exact berekend met mathjs, geen giswerk.
  • 📖 Wikipedia — live doorzocht in het Nederlands én Engels; treffers worden op relevantie herschikt (titel-match telt zwaarder dan een toevallig woord), en het beste treffer wordt met eigen code samengevat tot een lopende alinea.
  • 🦆 DuckDuckGo — live "instant answers" die de Wikipedia-samenvatting aanvullen waar nuttig.
  • 📚 Microsoft Learn, Google, Bing — als directe doorklik-knoppen, want die kunnen niet zonder eigen server rechtstreeks worden ingeladen.
  • 💬 Gespreksgeheugen — de laatste vragen blijven zichtbaar in de chat, zodat vervolgvragen in context staan.

Omdat er geen taalmodel meeleest, kan Lumen niet écht "redeneren" over tegenstrijdige bronnen of dingen buiten wat er letterlijk in de fragmenten staat — hij zet ze alleen zo leesbaar mogelijk voor je neer.

🧮 Rekenmachine (altijd exact) 📖 Wikipedia (live, NL + EN) 🦆 DuckDuckGo (live) 📚 Microsoft Learn (snelkoppeling) 💬 Onthoudt het gesprek 🚫 Geen AI-model — pure logica
