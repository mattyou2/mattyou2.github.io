ℹ️ Over beveiliging

Jouw API sleutel is veilig. De anon sleutel van Supabase is ontworpen om publiek te zijn — Supabase's Row Level Security (RLS) bepaalt wat wie mag zien en bewerken.

  • Klanten kunnen alleen actieve producten lezen en bestellingen plaatsen.
  • Producten bewerken, verwijderen en bestellingen inzien kan alleen als je bent ingelogd als beheerder.
  • De geheime service_role sleutel staat nooit in de frontend code.

Stel dit in via Supabase Dashboard → Authentication → Policies.
